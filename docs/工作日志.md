## 验证结果（2026-10-14）

- `flutter analyze`：**4 个 issue，全部为改动前既有**，本次改动零新增。
  - `player_controller.dart` `unawaited_return_in_try_block`（第 657 行，
    原为 618 行）：`_resolvePlayUrl` 内的音质降级重试，改动前就存在。
    **未修**：加 `await` 会让降级请求失败时再进入一次 catch，改变降级语义，
    需单独设计，故保留并在此登记。
  - `music_audio_handler.dart` 参数名不匹配（既有）。
  - `settings_page.dart` 两处 Radio 弃用（既有）。
- `flutter test`：**27 → 32 个测试全部通过**（新增 5 个缓存 source 回归测试）。
- 签名专项（见 `fixes/14-signing-secret-untrack.md`）：
  - `git ls-files | grep -E "keystore|key.properties"` → **无输出**（签名文件均未被跟踪）。
  - `restore-signing.ps1` 从 DPAPI 备份端到端实测：删掉本地 keystore 与
    `android/key.properties` 后完整还原，解密后 SHA256 与原文件一致
    （`659D22FB…BC7BC`），并生成 ACL 仅当前账户可访问的 key.properties。
  - **未执行**：git 历史清理（force push）与密钥轮换 —— 属破坏性操作，
    按工作区规则需用户明确指令，详见该说明文件的「残留风险」一节。
- 包名 / beta 分支（见 `fixes/15-package-rename-and-beta-branch.md`）：
  - 全仓库 `grep "hoilai\.mm"` **无残留**；3 个 Kotlin 文件的 `package` 声明、
    目录路径、`overlay_lyrics.xml` 自定义 View 全限定名、歌词广播 action 前缀
    已同步改写。
  - beta 流水线与正式流水线在触发分支 / 版本码基数 / R2 路径 / Release 类型
    四个维度全隔离，**不写根目录 `latest.json`**。
  - **本机无 Java 与 Android SDK，未做本地编译验证**，首次 beta CI 构建
    即为编译验证。
- 音效预设（见 `fixes/16-dts-style-equalizer-presets.md`）：
  - 新增「浩渺声场」「悦耳人声」两个 10 段预设，用系统均衡器对齐 DTS 的
    听感方向（不是厂商 DSP 算法复刻，已在代码注释与说明文件中写明）。
  - 新增 `test/equalizer_presets_test.dart` 5 个回归测试：预签名唯一、
    段数为 10、增益在 ±12dB、新预设存在、`equalizerPresets.first` 仍是
    「平直」（`resetEqualizer()` 依赖）。
  - `flutter test`：**32 → 37 个全部通过**；`flutter analyze` 仍为改动前

## 未执行项登记（`修复.txt` 中列出但本轮未做，需后续排期）

以下均为分析报告中列出、本轮**未改动**的项目，在此登记原因，避免后续
维护时误以为已修：

### 代码质量类
1. **明文凭证**：`token/t1/sessionId` 仍明文存 SharedPreferences。
   未做原因：切换 `flutter_secure_storage` 需迁移历史凭证并处理降级。
   （同组的「keystore 入库」已于 2026-10-14 修复，见
   `fixes/14-signing-secret-untrack.md`。）
2. **原生更新通道死代码**：`MainActivity.kt` 的 `downloadAndInstallApk`
   通道无人调用，与 Dart 侧 `launchUrl` 两套并存。未做原因：二选一需要
   产品决策（是否要通知栏下载进度）。
3. **update.md 与 pubspec 版本漂移**（update.md 记到 v3.1.19，pubspec 为
   3.1.2）。未做原因：属发版流程问题，按工作区规则需用户明确指令才改版本号。

### 性能类
4. **SharedPreferences 承载过重数据**：队列 JSON、500 条历史、缓存索引
   仍全部在 prefs 中。属大改动（需迁移方案 + 双写过渡），未做。
5. **节奏游戏每帧整页 setState**（`rhythm_game_page.dart`）：未做，属
   该页面独立重构。
6. **首页/我的页监听粒度过粗**（`home_page.dart:1357`、`library_page.dart:278`）：
   未做，需改为 Selector 式按需订阅。
7. **主 isolate 同步 IO**（`download_service.dart` 的 `listSync`）：
   未做，需迁移到 `compute()`。
8. **取消收藏需全量拉歌单反查 fileid**（`auth_controller.dart`）：未做，
   需新增 hash→fileid 本地映射缓存。

### 结构类

   建议单独分支进行，避免与功能改动混在一起。
10. **三套重复的播放加载流程收敛**、**四标志完成竞态简化**：未做，
    风险较高，需专门设计。

### 平台/体验类

    改造涉及加载流程重写，且本轮无法真机验证音质/进度表现。
12. **Android PiP 小窗播放**、**Windows 窗口管理/托盘**、**桌面快捷键扩展**、
    **手势操作**、**国际化 l10n**：均为新增功能，本轮未排期。
