# 16 · 新增「浩渺声场」「悦耳人声」预设音效

**批次**：音效 · **日期**：2026-10-14 · **状态**：已完成

## 问题现象

用户参照手机厂商（高通 DTS）的音效面板，希望把其中两个预设——**浩渺声场**
（"音符在辽阔声场中自由跳动"）和 **悦耳人声**（"高保真人声"）——加进
REIKO 的自定义音效预设列表。

现有 13 个预设（流行 / 摇滚 / 人声 / 低音 / 古典 / 电子 / 爵士 / 舞曲 /
嘻哈 / 民谣 / 乡村 / 3D环绕 / 蝰蛇音效）都是通用 EQ 曲线，没有针对
「空间感」和「人声清晰度」的专门预设。

## 根因 / 约束

厂商音效（DTS、ViPER4Android 等）是**芯片级 DSP**：多段动态 EQ、实时响度
控制、空间音频渲染，跑在音频 HAL 之后。本项目的音效能力来自 Android 系统
的 `android.media.audiofx.Equalizer` / `BassBoost`（经 MethodChannel
`kgka_music_hl/audio_effects` 调用），只有**固定频段的静态增益**。

因此这不是「把厂商算法搬进来」，而是**用系统均衡器去对齐听感方向**。
任何声称复刻的说法都是误导，故在代码注释里明确写了这一点。

## 改动内容

### 1. 新增两个预设（`lib/controllers/player_controller.dart`）

频段顺序沿用系统 EQ 的 10 段中心频率：
31 / 62 / 125 / 250 / 500 / 1k / 2k / 4k / 8k / 16k Hz

| 预设 | levels（单位：0.01dB，即 600 = +6dB） | 设计意图 |
|------|------------------------------------------|----------|
| **浩渺声场** | `[600, 500, 250, 0, -200, -250, -100, 200, 450, 550]` | 超低频打底但克制；500~1k 凹陷制造纵深与「在场感」；8k~16k 大幅延展做空气感。整体是「深—凹—亮」的碗形曲线，空间感在四个预设里最强。 |
| **悦耳人声** | `[-150, -100, -50, 150, 250, 450, 500, 350, 200, 100]` | 削超低频与浑浊中低频；增益集中在 1~4kHz（基频清晰度 + 临场感）；齿音区 8kHz 只给 +2dB，避免「刺耳」。 |

与既有「人声」预设的区别：「人声」幅度更大（1k 处 +5.5dB）偏染色，
「悦耳人声」幅度克制、整体更平，适合长时间聆听。

### 2. 新增回归测试（`test/equalizer_presets_test.dart`）

5 个测试，锁住三条容易在后续加预设时被破坏的不变量：

1. **预签名唯一** —— UI 靠 `equalizerPresetName` 字符串判断选中项并打勾，
   重名会让勾选标记出现在两处；
2. **每段都是 10 个值** —— `_levelsForBandCount` 按下标比例重采样到设备
   实际段数，段数不对会错位（大多数国产/国际机型是 5 段）；
3. **增益在 ±1200（±12dB）内** —— 超范围会被系统 EQ 裁剪，回读曲线
   与预设名对不上。

另加：两个新预设存在性、`equalizerPresets.first` 仍是「平直」
（`resetEqualizer()` 依赖它）。

## 回归风险与注意事项

1. **听感是主观的**，两条曲线是按 DTS 的听感描述设计的起点，不是终点。
   若用户觉得某个方向不对，直接改 `levels` 里的数字即可（单位 0.01dB，
   范围 ±1200），无需改结构。
2. **预设只改均衡器，不动低音增强开关**。浩渺声场的低频主要靠 EQ 曲线
   前三段实现，没有自动打开 BassBoost——若日后要「预设联动低音增强」，
   需要给 `AudioEffectPreset` 增加字段并改 `applyEqualizerPreset`，
   属于独立改动。
3. 老用户已保存的 `settings.equalizer_preset` 若与新预设**同名**会被
   识别为新曲线；本次新增的名字与既有 13 个无冲突，已由测试锁死。
4. 厂商音效里「限免 1 天」的**环绕剧院 / 悠扬舞台**本次未加（用户框选的
   是前两个免费项），需要的话可按同样方式补。
